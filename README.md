# HEY-SMITH ライブスケジュール AIアシスタント（RAG Chatbot）

HEY-SMITH 公式サイトのライブ情報を自動スクレイピングし、AI（GPT-4o-mini）が整形したデータをベクトルデータベース（Chroma）に保存。「次のライブはいつ？」「東京でやる公演は？」といった質問に、実際の公式スケジュールだけを根拠に答える RAG（検索拡張生成）チャットボットです。

好きなバンドのライブ情報を公式サイトで毎回探すのが面倒、という自分自身の課題を解決するために開発しました。

## 主な機能

- **公式サイトの自動スクレイピング** — 2026年6月〜2027年12月の月別ライブ情報ページのURLを自動生成し、一括で読み込み
- **AIによるデータクレンジング** — スクレイピングした生テキストから【日時】【会場】【出演者】【フェスツアー名】の4項目だけをLLMが抽出し、メニューや挨拶などのノイズを除去
- **ベクトルDBへの永続化** — 整形済みデータを Chroma に保存。2回目以降の起動はスクレイピングとAI整形をすべてスキップし、既存DBを一瞬で読み込み（API利用料と時間を節約）
- **RAGによる正確な回答** — 質問に関連するスケジュールをベクトル検索で取り出し、その情報だけを根拠に回答。プロンプトで「情報にない事実を答えない」よう制約し、ハルシネーションを抑制
- **対話型インターフェース** — ターミナル上でチャット形式で質問可能。「バイバイ」「exit」で終了

## スクレイピング結果の例

AIが整形したデータは以下のような形式でDBに保存されます（実際の出力例は [heysmith_schedule.txt](heysmith_schedule.txt) を参照）:

```
- **日時**: 2026.11.07 (Sat)
  - **会場**: ZOZOマリンスタジアム
  - **出演者**: HEY-SMITH
  - **フェスツアー名**: AIR JAM 2026
```

## 動作環境

- Python 3.10 以上
- OpenAI APIキー（有料・従量課金）
- インターネット接続

## インストール

```bash
git clone https://github.com/awa4000/RAG_hey.git
cd RAG_hey
pip install -r requirements.txt
```

プロジェクト直下に `.env` ファイルを作成し、OpenAI APIキーを設定します:

```
OPENAI_API_KEY=sk-あなたのAPIキー
```

## 使い方

```bash
python heysmith.py
```

| 操作 | 動作 |
|---|---|
| 初回起動 | スクレイピング → AI整形 → ベクトルDB構築（数分かかります） |
| 2回目以降の起動 | 既存DB（`./chroma_db`）を読み込み、すぐに対話開始 |
| 質問を入力 | スケジュールを検索してAIが回答 |
| 「バイバイ」「exit」「quit」 | アプリを終了 |

質問の例: 「8月のライブを教えて」「東京ガーデンシアターの公演は誰と対バン？」

## 技術的なポイント

- **RAGパイプラインの構築** — LangChain の LCEL 記法で「検索機（Retriever）→ プロンプト → LLM → パーサー」を1本のChainとして宣言的に組み立て、質問に関連する上位3件の文脈を検索して回答を生成しています
- **LLMをデータ整形に活用** — 従来は正規表現やHTMLパースで行っていたスクレイピング後のデータクレンジングを、プロンプト設計によってLLMに任せることで、サイトのレイアウト変化に強い柔軟な抽出を実現しています
- **DBのキャッシュ戦略** — `chroma_db` フォルダの存在チェックにより、初回のみ構築・以降は再利用する設計にし、起動時間とAPI利用料を大幅に削減しています
- **ハルシネーション対策** — RAG用プロンプトで「提供された情報だけを根拠に答え、含まれていない事実を答えない」よう明示的に制約しています

## 制限事項・注意

- OpenAI API の利用には**従量課金の費用**が発生します（gpt-4o-mini と text-embedding-3-small を使用しており、初回構築でも少額です）
- スクレイピングは**個人利用・学習目的**を想定しています。公式サイトへの負荷を考慮し、頻繁なDB再構築は行わないでください
- 公式サイトの構造が変わると、抽出がうまく動かなくなる可能性があります
- 最新情報に更新したい場合は `chroma_db` フォルダを削除して再起動してください
